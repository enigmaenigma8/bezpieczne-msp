# Bezpieczne MSP

Automatyczna ochrona poczty elektronicznej dla małych i średnich przedsiębiorstw.

## Cel

Narzędzie analizuje przychodzące wiadomości e-mail pod kątem phishingu i typowych zagrożeń występujących na polskim rynku. Generuje alert wyłącznie przy podwyższonym ryzyku, wraz z jasną rekomendacją.
